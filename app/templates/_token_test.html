Test your token

Run this in a terminal (macOS, Linux, or Windows with curl.exe):

If the token works, the answer is JSON describing it: your "email", your account under "user", the "token_type" (personal, application or course) and, for a course token, the course with its dates.

If it does not, the answer has HTTP status 401 and "valid": false, a "reason" and an explanation in "error_description". The reason is malformed when the token was copied incompletely or with extra characters, unknown_or_revoked, expired, or for a course token course_not_started, course_ended or course_closed. Add -i after curl to see the status line.
