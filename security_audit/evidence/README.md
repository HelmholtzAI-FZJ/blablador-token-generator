## Reproduction and outstanding environment evidence

Project tests force synthetic configuration and keys. `TEST_DATABASE_URL` enables destructive fixture create/drop operations: use only a disposable instance. The real privilege integration case additionally recognizes the known isolated loopback audit credentials/port; ordinary CI PostgreSQL still runs behavioral tests and mock startup-policy assertions, and may skip that narrowly guarded integration case.

The [probe guide](../probes/README.md) describes isolated image/store verification. [Operations](../OPERATIONS.md) covers authorized release and upgrades. Production ingress, CNI, IdP/MFA/offboarding, managed database grants, key rotation, backups/restore, target-architecture registry digests and representative load still require actual environment evidence. No registry push, production migration or deployment occurred during this audit.
